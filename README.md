## Upload to GitHub

1. Create a new GitHub repository, or open the repository that will host this site.
2. Upload **all files and the `assets` folder inside this folder** to the repository root. Do not upload only the outer folder.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then click **Save**.
7. In the same Pages settings, set the custom domain to `rekhaastrology.in` and enable **Enforce HTTPS** after GitHub makes the option available.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Before starting Google Ads

- Open every page on the live `https://rekhaastrology.in` domain and confirm it loads without an error.
- Test every WhatsApp button on both a phone and a desktop browser.
- Keep the business name in the Google Ads account and ad creative consistent with **Rekha Astrology**.
- Make sure the ad describes the same WhatsApp contact destination and business identity visible on the landing page.
- Do not use guaranteed-result claims, fear-based claims, false deadlines, invented awards or an affiliation that cannot be proved.
- If an ad mentions a price, product or offer, add the same accurate information to the landing page before advertising it.
- If you add Google Ads conversion tracking, Analytics, Meta Pixel or another non-essential tracker later, update the Privacy Policy and add any consent mechanism required for the countries you target.
- Keep invoices, award evidence, testimonial permissions and service records available in case Google requests business verification.

Google reviews the whole ad setup, not only the website. A compliant-minded landing page can reduce avoidable issues, but no developer can guarantee ad approval.
